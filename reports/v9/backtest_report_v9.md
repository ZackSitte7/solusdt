# SOL/USDT 4h 多因子 LGBM 回测报告 (v9: long+short 共同优化, 合并总收益)
- 数据源: 欧易(OKX) 4h 现货 SOLUSDT | 清洗后 10942 根(起点 2021-10-01)
- 切分: train 70% / OOF 15% / OOC 15%, 按时间顺序
- v9 **两侧都重做**: long / short 各为一个模型, 在 OOF 上**联合选优合并总收益**(v7/v8 的 long 冻结自 v6, v9 不再冻结)。
- 选择: **只在 OOF 子折**; **OOC 仅观察**。合并口径: `equity = eq_long + eq_short - INIT_CAPITAL` => **合并收益 = 两侧收益之和**。
- 阶段1: 每侧按该侧稳健收益(折均收益 - 1.0×折间std, 单折>=15笔)取前 200 个候选;
  阶段2: 对 (long候选 × short候选) 以合并稳健分 = 合并收益折均 - 1.0×折间std 为主目标, 最差折合并收益为次目标。
