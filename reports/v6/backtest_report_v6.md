# SOL/USDT 4h 多因子 LGBM 回测报告 (v6: 扩充因子库 + 跟踪止损 + 波动率制度)
- 数据源: 欧易(OKX) 4h 现货 SOLUSDT | 清洗后 10942 根(起点 2021-10-01)
- 切分: train 70% / OOF 15% / OOC 15%, 按时间顺序
- 选择: **只在 OOF** 上联合择优(收益优先、夏普次之); **OOC 仅观察**, 不参与任何选择
- 因子池: `core", "expanded` —— 每个池各自做 IC/ICIR 筛选 + 去冗余 + VIF 剪枝, 由 OOF 决定用哪个池
- 因子库: 扩充到 126 个(波动率结构 / 高阶矩 / 自相关 / 趋势强度 / 量能资金流 / 形态统计)
- 执行: 止盈/止损为 ATR 倍数(**tp > sl**), 并加入 **ATR 跟踪止损**; 阈值分位上限放宽到 0.90
- 制度门控: `none", "sma100", "sma200_slope", "atr_pct`(含 atr_pct 低波动率门控), 规则一并交给 OOF 选优
