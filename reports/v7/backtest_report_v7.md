# SOL/USDT 4h 多因子 LGBM 回测报告 (v7: 空头模型优化)
- 数据源: 欧易(OKX) 4h 现货 SOLUSDT | 清洗后 10942 根(起点 2021-10-01)
- 切分: train 70% / OOF 15% / OOC 15%, 按时间顺序
- v7 **只优化空头**; 多头沿用 v6 冻结配置(见 reports/v6)。
- 选择: **只在 OOF** 上联合择优; **OOC 仅观察**, 不参与任何选择
- 新增空头因子: 下行动量分解、破位与支撑阻力距离、结构走弱(高/低点同步下移)、相对自身历史超卖、跳空低开统计
- 新增空头制度: `none", "sma100", "sma200_slope", "atr_pct", "sma_align", "ema_bear", "breakdown_20", "bear_vol`(全部只用过去信息)
- 执行网格: 止损下探到 0.35×ATR(相对 v6 的 0.50 更宽); 抗过拟合仍做 VIF<=10 剪枝
