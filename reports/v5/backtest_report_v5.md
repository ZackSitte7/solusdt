# SOL/USDT 4h 多因子 LGBM 回测报告 (v5: 制度门控 + VIF 剪枝 + OOF 选优 + ATR 止盈止损 tp>sl)
- 数据源: 欧易(OKX) 4h 现货 SOLUSDT | 清洗后 13128 根
- 切分: train 70% / OOF 15% / OOC 15%, 按时间顺序
- 选择: **只在 OOF** 上选优(收益优先、夏普次之); **OOC 仅观察**, 不参与任何选择
- 执行: 止盈/止损均为 **ATR 倍数**, 且**硬约束 tp > sl**(风险报酬比 > 1)
- 抗过拟合: 因子集做 **VIF 迭代剪枝**(全部 VIF <= 10);
- 制度门控: `none", "sma100", "sma200", "sma200_slope` —— long 仅当 close>MA, short 仅当 close<MA, 规则一并交给 OOF 选优
