# SOL/USDT 4h 多因子 LGBM 回测报告 (v14: 为 long 加趋势因子 + 优化 long 模型/模型层/执行层)
- 数据源: 欧易(OKX) 4h 现货 SOLUSDT | 清洗后 10942 根 | **起点对齐 DATA_START=2021-10-01**(首根 2021-10-01 00:00)
- 切分: train 70% / OOF 15% / OOC 15%, 按时间顺序
- 选择规则(同 v13): 真实 OOF 段上 **收益锚 + 夏普择优** —— 取 OOF 收益最高者为锚, 在「OOF 收益 >= 锚收益 - 0.0150(让出上限 1.50 个百分点)」的有界让步带内取 OOF 夏普最高者; 让步带用**绝对值**(收益可能为负, 比例门槛会方向错误)。
- 选择**只在 OOF**; **OOC 仅观察**, 不参与任何选择
- 执行: 止盈/止损均为 **ATR 倍数**, 且**硬约束 tp > sl**(风险报酬比 > 1)
- 抗过拟合: 因子集做 **VIF 迭代剪枝**(全部 VIF <= 10);
- 制度门控: `none", "sma100", "sma200", "sma200_slope` —— long 仅当 close>MA, short 仅当 close<MA, 规则一并交给 OOF 选优
- 与 v13 的关系: 成本 / 资金 / 切分 / 标签 / VIF 纪律 / 选择规则**完全一致**; v14 只强化 long —— (1) 新增 **7 个趋势因子**; (2) 模型候选 7 个(新增 deep_reg2 / mid_reg); (3) 执行网格再外扩(阈值 0.30~0.80 / tp 1.0~6.0 / sl 0.5~3.0 / hold [6, 12, 24, 36, 48, 72])、去冗余网格 [0.8, 0.85, 0.9, 0.95, 0.97, 0.99]; **short 逐位不变**(仍用 v13 原网格 + 排除 long 专用因子)
